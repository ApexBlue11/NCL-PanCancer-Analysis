# Pan-cancer analysis of Nucleolin (NCL)

Reproducible computational workflow for a pan-cancer characterisation of Nucleolin (NCL) across 33 TCGA cancer types, with GTEx normal references, independent CPTAC protein-level validation, and multivariable survival modelling.

This repository accompanies a revised manuscript submitted to the *Eurasian Journal of Medicine and Oncology*. It contains everything needed to reproduce every number and figure in that manuscript from public data.

---

## Summary of findings

- **NCL is broadly overexpressed.** Significantly elevated in 24 of 29 evaluable cancers (Cliff's delta up to +0.93), and reduced in ovarian carcinoma. Confirmed at the **protein** level in 7 of 9 independent CPTAC cohorts.
- **It is rarely an independent prognostic factor.** Across 74 multivariable Cox models spanning three endpoints, NCL survived covariate adjustment and FDR correction in **two**: KIRP (overall and disease-specific survival) and ACC (progression-free survival).
- **Its immune association is with tumour-intrinsic ligands, not T-cell checkpoints.** NCL correlates with **B7-H3 (CD276)** in 21 of 33 cancers after adjusting for both tumour purity and proliferation, and with CD73 and CD39 in 17 each — while CTLA-4 (4/33), PD-1 (3/33) and TIM-3 (9/33) are largely uncorrelated.
- **NCL marks an immune-excluded phenotype.** Negatively correlated with the xCell microenvironment score in all 20 cancers where significant, and with immune score in 18 of 20.
- **Deconvolution algorithms frequently disagree.** Of 330 cancer × cell-type combinations, only 25% were concordant across algorithms and **33% produced significant associations of opposite sign** depending on the algorithm used.
- **The normal comparator changes the answer.** In KIRP, KICH, KIRC and THCA the direction of NCL dysregulation reverses between GTEx and adjacent-normal references.

## Quick start

```bash
pip install -r requirements.txt
python scripts/test_statsutil.py       # verify statistical utilities (should print ALL PASS)
python scripts/00_check_sources.py     # confirm all data URLs are reachable
```

Then run the pipeline in order (see [METHODOLOGY.md](METHODOLOGY.md) §4):

```bash
python scripts/01_download.py
python scripts/02_fetch_clinical.py
python scripts/03_build_matrix.py
python scripts/04_expression.py
python scripts/05_survival.py
python scripts/06_immune.py
python scripts/07a_expression_filter.py
python scripts/07_gsea_correlations.py
python scripts/07_gsea.py --workers 4
python scripts/08_cptac_validation.py
python scripts/09_manuscript_numbers.py
python scripts/10_figures.py
```

Every script is idempotent — it skips work whose output already exists — so an interrupted run can simply be restarted.

**Requirements:** Python 3.14, ~6 GB free disk, <1 GB RAM. Total runtime ≈ 90 minutes, dominated by GSEA. No proprietary data or credentials are needed; every input is public.

## Statistical approach

- **Effect sizes everywhere.** Cliff's delta with bootstrap 95% CIs for group comparisons; Hedges' *g* alongside; hazard ratios per standard deviation with 95% CIs; Spearman ρ with Fisher-*z* CIs.
- **Multiple testing.** Benjamini–Hochberg FDR within every family of tests; significance at q<0.05 throughout.
- **Confounder control.** Immune correlations are purity-adjusted. Checkpoint correlations are additionally adjusted for a ten-gene proliferation score, because NCL is a proliferation-coupled gene and an unadjusted correlation may simply restate that.
- **Assumption checking.** Proportional hazards tested via Schoenfeld residuals for every Cox model; violations reported and flagged on the figures.
- **Trend testing.** Stage association uses Jonckheere–Terpstra, which tests a monotonic trend across ordered stages — not a comparison of each stage against normal tissue, which does not test a trend at all.

`test_statsutil.py` verifies each utility against brute-force or published reference implementations before use, including a null-calibration check (5.7% type-I rate at α=0.05) and a check that a non-monotonic pattern is *not* reported as a trend.

## Reproducibility

- All stochastic steps are seeded (`seed=0`): bootstrap CIs (2,000 resamples) and GSEA permutation (1,000 permutations).
- Every script writes to disk before the next reads, so any step can be re-run in isolation.
- `09_manuscript_numbers.py` regenerates every number quoted in the manuscript from the result tables, so a changed analysis surfaces stale text rather than leaving it silently wrong.
- The environment is pinned in `requirements.txt`.

## Relationship to the previous version

This is a revision. Peer review prompted a full reanalysis, and several previous conclusions did not survive it. [METHODOLOGY.md §8](METHODOLOGY.md) lists every correction with the evidence, including: immune-checkpoint and CancerSEA claims that were asserted without any corresponding analysis; a stage-progression claim supported in 1 of 8 named cancers on formal testing; three Kaplan–Meier panels labelled with the wrong cancer; a differential-expression method misattributed in Methods; and a cancer-abbreviation table that was not a TCGA list.

These are documented openly because the errors are of a kind that readers cannot detect from a published record alone.

## Limitations

This workflow generates **no new experimental data**. CPTAC provides independent, orthogonal, protein-level, paired validation of the overexpression finding, but it tests none of the mechanistic hypotheses. In particular, the NCL–B7-H3 association is correlational: nothing here shows that NCL regulates B7-H3, and establishing that would require perturbation experiments. See [METHODOLOGY.md §9](METHODOLOGY.md).
